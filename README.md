## ⚙️ How This Repo Works

1. Solve a problem on [LeetCode](https://leetcode.com) in Java
2. On **Accepted**, [LeetHub](https://github.com/arunbhardwaj/LeetHub-2.0) auto-commits the solution to this repo
3. A [GitHub Action](.github/workflows/organize.yml) picks it up, sorts it into `topics/<tag>/<problem>/`, generates a per-problem README, and rebuilds the tables above

Each problem folder contains:
- `README.md` — problem summary, approach, and time/space complexity
- `Solution.java` — the accepted solution
